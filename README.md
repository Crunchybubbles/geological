# Geological

Geological is a causal geology and terrain-generation mod for Minecraft Java 1.21.1 on NeoForge. It is intended to generate the canonical Overworld, Nether and End from dimension-specific geological histories rather than add a separate geology dimension.

This public repository is the home of the mod source, build configuration, tests, runtime data, releases and contributor-facing implementation documentation. The initial implementation scaffold has not been added yet.

## Stable identity

```text
display name: Geological
mod ID and data namespace: geological
Java base package: io.github.crunchybubbles.geological
license: MIT
```

## Repository boundary

Long-form research and pre-implementation planning are maintained separately. This repository will remain independently buildable: neither builds nor tests will require access to private planning material.
