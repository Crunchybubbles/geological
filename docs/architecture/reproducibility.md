# Reproducibility and random-access contract

## World identity

All identities include:

```text
world seed
model version
scientific digest
dimension profile ID
namespace/object type
home-cell coordinates and local index
purpose and explicit counter
```

The tuple is serialized with the deterministic subset of RFC 8949 CBOR used by `CanonicalCbor`. Text is UTF-8 NFC, integer encodings are minimal, and array order is schema-defined. HMAC-SHA-256 supplies both the root key derivation and domain-separated output. A `StableId` is the first 128 bits; full random/digest outputs remain 256 bits.

`RandomStream` is stateless. Every draw supplies an explicit purpose and counter. Adding a new draw cannot shift an existing object's decisions. `ObjectRandomStream` applies the same contract when an upstream stable object ID, rather than a home-cell/local-index tuple, owns a derived distribution. Bounded integers use rejection sampling and unit doubles use the leading 53 bits.

## Spatial ownership

Negative coordinates use mathematical floor division. A descriptor is compiled only from its home cell and world identity. Queries enumerate a bounded owner-cell neighborhood in stable coordinate/ID order, then evaluate exact fields. Bounded caches may retain immutable descriptors, atlas sites, and pure noise-lattice values, but are not geological truth; the cache-independence tests disable all three layers.

## Numeric policy

Identity and ledgers use integers/bytes only. Continuous fields use `StrictMath`, local coordinates relative to an owning site, explicit clamping, and deterministic stable reductions. Seam tests include negative coordinates, exact tile borders, cache eviction, and arbitrary query order.

The tests include fixed HMAC/CBOR/ID golden vectors. Changing a vector is a world-identity change and requires an explicit model-version decision.

Adaptive colluvial routes expose their nominal routed distance, endpoint straight-line distance, bounded route-directness index, net source-to-target relief, and bounded route-grade index. The path response multiplies continuity and directness by a bounded route-grade response, so geometric detours and flat or net-uphill remote routes reduce transport efficiency deterministically while a zero-reach local path remains direct. These diagnostics and all per-reach routing decisions are derived from immutable terrain samples and are included in the causal body-ID purpose.

Generated colluvium evaluates immutable source-capacity tranches from the deterministic weathering depth, slope, normalized flow-accumulation runoff proxy, distance, resolved erodibility, and registry-authored sediment yield at each bounded sample. A bounded score selector labels each tranche as hillslope creep, sheetwash, or dry ravel from slope, runoff, route grade, and continuity; the selector is an auditable process proxy, while the explicitly named dry-ravel survival law remains the uncalibrated grain-transport parameterization. Canonical largest-remainder apportionment partitions capacity and mobilized mass into gravel-and-coarser, sand, and fines. `StrictMath` attenuation under the explicit fixed grain-transport model partitions each mobile grain inventory into transport loss and arrival; fixed-unit apportionment then partitions arrival into bypass and deposition. The transport-loss and bypass quantities additionally derive bounded receiving roles—intermediate route storage and downstream continuation—without inventing an exact receiving body or coordinate. A separate cohesion state derives fines fraction and matrix support, then keeps cohesion-adjusted detachment distinct from the effective erodibility response. Repeated source-body claims are grouped into deterministic usage summaries, with exact capacity and mobilized-mass closure checked for every group. Each source tranche's deposited grain spectrum is published separately, allowing source-to-grain provenance to reconcile exactly to the aggregate source portion without assigning minerals to grain classes. The deposited three-bin spectrum also derives bounded coarse, sand, and fines spread proxies and a weighted dispersion class; these are resolution aids rather than measured diameters. Every bulk equality therefore closes componentwise. Separate canonical reductions convert input deposit totals to exact mineral-mixture shares and aggregate deposited grain mass to the exact texture spectrum. The deposited three-bin spectrum also derives a bounded sorting-dominance index and coarse sorting class; this state feeds the existing texture-conditioned physical response without claiming mineral-specific distributions. The same immutable weathering availability and normalized source-versus-matrix shares derive a coarse colluvial profile class; no absolute thickness or organic reservoir is inferred. The transport-model identity, every response input, every process score, every sink role and fraction, every cohesion state, every dispersion state, every source usage summary, every source grain spectrum, every bulk and grain allocation, every delivered share, and the resulting state join the canonical colluvial body-ID purpose. No mutable draw, traversal state, or query order enters this derivation.

Phase 1 compiles its effective definitions, schemas, units, citations, and parameter provenance into compact canonical JSON. Inputs are sorted by stable ID, strings are UTF-8 NFC, and the full SHA-256 digest of those bytes is frozen into `WorldIdentity`. Input list/map order and authoring whitespace therefore cannot change identity, while any effective scientific parameter change must change it. The snapshot golden is published by the tests and as `registry-snapshot.json` in the review packet.

The authored source is a packaged public JSON resource with a versioned authoring schema. Duplicate keys, trailing content, unknown fields, and unit-vocabulary changes fail before canonical compilation. JSON parser objects never enter domain APIs, and the resource is loaded once when the Phase 1 registry initializes rather than during random-access queries.

Phase 0 and Phase 1 intentionally use different model, scientific-digest, and dimension-profile identities. Phase 0 retains the fixed fertile proof grammar; Phase 1 adds deterministic grammar selection, revised deformation, explicit stratigraphy, and the validated registry digest. A Phase 1 result can therefore never masquerade as Phase 0 geology for the same numeric seed.

Phase 2 freezes its typed material catalog independently, then hashes a canonical manifest containing the unchanged Phase 1 registry digest and the material-catalog digest. Its distinct model/profile identity prevents petrologic results from masquerading as Phase 1 geology. Each body samples its authored modal-variation axes and bounded physical properties through object-keyed, purpose-separated streams, so cache state and unrelated draws cannot perturb a realization. Variation axes are canonically ordered and contain signed loadings that close to zero, making mineral covariance explicit rather than dependent on map iteration or independent per-mineral noise. Solid-solution definitions and endmember IDs are canonically sorted; resolved component volume and formula-mass-corrected mole fractions use stable largest-remainder allocation and therefore close exactly without authoring/map-order dependence. Protolith-family lists and response recipes are canonicalized before hashing, and the resolver chooses exactly one target from the immutable host family; authoring order cannot change that choice. Discrete fluid-condition axes are authored and canonicalized rather than randomly consumed during queries. Mineral modes and formula-derived bulk element mass fractions close on an exact one-million-part basis; domain-separated largest-remainder tie ranks remove iteration-order and floating-point residuals before values enter local element-delta or system reservoir ledgers. Surficial weathering targets explicitly retain the one-part-per-million native-gold carrier so exact blending cannot erase source-linked placer identity when unrelated world identity changes alter a rounding tie. A generated colluvial mantle derives a normalized uphill vector from bounded four-block central differences of deterministic Phase 1 surface elevations, then follows shared adaptive 32-block reaches whose local gradients are clipped to the initial 60-degree bearing bound before sampling deterministic local, near-upslope, and far-upslope bedrock at cumulative distances. The route thresholds, spacing, distances, deflection, and capacity split are carried by an immutable policy that may be injected for calibration without changing Phase 1 identity. Each contribution records its exact source point and owning province; construction validates that every point lies at its declared distance on the canonical routed path. Its transported body ID is derived through a purpose-separated object stream keyed by the local source body and separated by composition-relevant source attributes and matrix fraction. An exact N-way largest-remainder blend combines the body-keyed generic matrix and source assemblages independently of list order, after which bulk chemistry and solid-solution state are recomputed. Cache eviction and query order therefore cannot change classification, provenance, identity, modal closure, or chemistry.

Linked pluton pulses additionally derive a typed `MagmaDifferentiationState` from their canonical pulse order. Source-reservoir IDs are sorted and unique; the proof arc uses explicit melting, source, sulfur, assimilation, and differentiation categories; cumulative crystal fraction plus residual melt fraction closes exactly to one million normalized parts; and the lineage's legacy floating progress is checked against that fixed-point ledger. Residual-fluid potential is an explicit bounded enum and fertility tags are sorted, unique pathway hints; they do not create ore mass, deposit bodies, or a calibrated volatile/trace-element budget. The state is immutable query evidence rather than a hidden draw or an absolute melt/trace-element budget.

Metamorphic histories additionally derive a typed `MetamorphicProcessState` from the authored grade, facies, path, and alteration response. Burial-curve, strain/fabric, fluid-availability, reaction, mass-transfer, and retrogression fields are bounded and deterministic; mass-transfer processes require authored fluid evidence, while isochemical/contact and regional paths retain zero transfer. These proxies are query evidence and do not introduce a mutable world field or equilibrium solver. An optional `RegionalMetamorphicState` reuses the stable `FOLD` chronicle event and evaluates its continuous local taper to expose bounded, intensity-zoned regional grade, facies, collision path, peak P-T, strain, and intensity; points outside the authored fold return no regional field state, and no new Phase 1 event or body is generated.

Sedimentary histories additionally carry a canonical `SedimentaryInputBudget` and a matching list of `SedimentaryReservoirContribution` records. Clastic, volcanic, carbonate, organic, chemical-precipitate, and evaporitic-brine components are non-negative fixed-point parts that close exactly to one million; terrigenous and volcanic-ash entries retain sorted source-body IDs, while authigenic carbonate, organic, chemical, and brine entries explicitly carry empty source lists. The facies mapping is deterministic and independent of query order. This is a named source/reservoir proof attached to the typed basin context, not an absolute basin flux or a hidden seawater/organic reservoir.

The matching `SedimentaryDiagenesisState` is also canonical proof evidence: compaction, cementation, dissolution, dolomitization, organic maturity, fluid salinity, and retained-porosity are bounded facies responses, and the fluid salinity must equal the basin salinity. These values are not physical burial measurements or a coal-rank solver.

Generated element-reservoir transfers carry optional compatibility metadata as canonical process ID, formation age, and confidence parts-per-million. Formed-system compilation populates all three for every exact sink allocation, while the transfer amount remains the quantity used by the closure check; missing metadata is allowed only for legacy callers using the four-argument constructor.

Metamorphic event IDs are paired with `AgeKey` values from one canonical chronicle ordering. `MetamorphicHistory.eventTimeline()` is the authoritative complete pair view; the compatibility `eventIds()` and `eventAges()` projections are derived from the same ordering whenever both lists are present. Generated histories therefore retain explicit event timing for contact, regional, hydrothermal, and weathering paths; legacy construction may leave the age list empty when only IDs are available.

Each material result also exposes one `AlterationContribution` assembled from the same immutable inputs as the process ledger, metamorphic process state, and resolved assemblages. Its signed mineral-mode delta closes to zero, its positive/negative element maps match the process ledger, and its response/fluid fields obey the authored process class; it is a joined explanation view, not an additional source of random draws or mass.

Metamorphic process state additionally carries a canonical `MetamorphicReactionState`. Reaction-family and retrogression classes plus dehydration, decarbonation, and partial-melting fractions are bounded; typed `fluidContributions` expose the corresponding water or carbon-dioxide input/output evidence. The canonical validator requires dehydration, decarbonation, and serpentinization contributions to agree exactly with their reaction channels; unsupported channels remain empty. Serpentinization uses an exact normalized balance (`rock reactant + fluid input = serpentine product + residual rock + residual fluid`) so the hydration proof cannot create or lose inventory, while these contributions remain provenance evidence rather than a calibrated fluid-flow budget.

High-grade contact responses receive optional host-lithology context. Carbonate-rich limestone, dolostone, marble, and carbonatite hosts emit the bounded decarbonation CO₂ contribution; the solid-rock element ledger remains isochemical because volatile release is represented as reaction evidence, not an unmodeled mass-transfer delta. Non-carbonate contact hosts retain thermal recrystallization.

High-grade collisional amphibolite-facies granitic gneiss receives a bounded partial-melting reaction response. Its normalized fraction is deterministic and carried in `partialMeltingPpm`; no absolute melt volume, child body, or fluid ledger is implied.

Each generated magma pulse also carries `residualFluidFractionPpm`, a normalized subset of its residual melt. The canonical state enforces `0 <= residualFluidFractionPpm <= residualMeltFractionPpm` and crystal-plus-residual-melt closure; compatibility construction defaults the new field to zero. It is comparative lineage evidence, not an absolute volatile inventory.

Metamorphic process state carries `strainIntensityPpm` alongside its categorical `strainClass`. Generated path responses use deterministic bounded values and the canonical constructor enforces the normalized range; the compatibility constructor defaults to zero. This is a coarse fabric-response proxy, not a tensor, orientation field, or calibrated strain rate.

The metamorphic path enum is also canonical and review-visible. Burial heating, cold subduction, decompression exhumation, and polymetamorphic reworking map to distinct burial-curve and retrogression responses with bounded strain evidence; their regional reaction proof remains fluid-free until a future calibrated reaction model is authorized.

Each metamorphic process also carries a canonical principal-axis frame. Active frames expose normalized shortening/flattening/stretching shares that close exactly, plus bounded foliation azimuth and lineation trend/plunge; inactive state is all zero. Path and fabric classes select the frame deterministically, so orientation evidence does not consume random state or become cache-dependent.

The normalized colluvial production/transport response has its own immutable policy for availability floors, path/roughness/grade response floors, grain attenuation distances, bypass response, and bounded process-specific mobilization factors. The policy is carried in each budget and input balance and is included in transported-body identity. A finite `ColluvialSourceClaimLedger` canonicalizes claims from multiple queried parcels and aggregates each source body with exact partition closure; its `ColluvialSourceCapacityLedger` companion can then consume an explicit, non-negative mobilized-inventory capacity per source body, apportion constrained claims by canonical largest-remainder shares, and return unallocated mobilized material to retained inventory with exact bulk and grain-stage closure. Grain-resolved constrained allocations are derived from each claim's exact three-bin spectrum and retain the scalar stage totals; they do not imply a measured source grain inventory. Both are deliberately read-only finite-query audits and never introduce mutable global depletion into random-access queries. Active sink allocations similarly retain exact representative Phase1 receiving-surface/bedrock evidence while leaving downstream sediment placement unresolved.
