# Reproducibility and random-access contract

## World identity

All identities include:

```text
world seed
model version
scientific digest
dimension profile ID
namespace/object type
home-cell coordinates and local index
purpose and explicit counter
```

The tuple is serialized with the deterministic subset of RFC 8949 CBOR used by `CanonicalCbor`. Text is UTF-8 NFC, integer encodings are minimal, and array order is schema-defined. HMAC-SHA-256 supplies both the root key derivation and domain-separated output. A `StableId` is the first 128 bits; full random/digest outputs remain 256 bits.

`RandomStream` is stateless. Every draw supplies an explicit purpose and counter. Adding a new draw cannot shift an existing object's decisions. `ObjectRandomStream` applies the same contract when an upstream stable object ID, rather than a home-cell/local-index tuple, owns a derived distribution. Bounded integers use rejection sampling and unit doubles use the leading 53 bits.

## Spatial ownership

Negative coordinates use mathematical floor division. A descriptor is compiled only from its home cell and world identity. Queries enumerate a bounded owner-cell neighborhood in stable coordinate/ID order, then evaluate exact fields. Bounded caches may retain immutable descriptors, atlas sites, and pure noise-lattice values, but are not geological truth; the cache-independence tests disable all three layers.

## Numeric policy

Identity and ledgers use integers/bytes only. Continuous fields use `StrictMath`, local coordinates relative to an owning site, explicit clamping, and deterministic stable reductions. Seam tests include negative coordinates, exact tile borders, cache eviction, and arbitrary query order.

The tests include fixed HMAC/CBOR/ID golden vectors. Changing a vector is a world-identity change and requires an explicit model-version decision.

Adaptive colluvial routes expose their nominal routed distance, endpoint straight-line distance, bounded route-directness index, net source-to-target relief, and bounded route-grade index. The path response multiplies continuity and directness by a bounded route-grade response, so geometric detours and flat or net-uphill remote routes reduce transport efficiency deterministically while a zero-reach local path remains direct. These diagnostics and all per-reach routing decisions are derived from immutable terrain samples and are included in the causal body-ID purpose.

Generated colluvium evaluates immutable source-capacity tranches from the deterministic weathering depth, slope, normalized flow-accumulation runoff proxy, distance, resolved erodibility, and registry-authored sediment yield at each bounded sample. A bounded score selector labels each tranche as hillslope creep, sheetwash, or dry ravel from slope, runoff, route grade, and continuity; the selector is an auditable process proxy, while the explicitly named dry-ravel survival law remains the uncalibrated grain-transport parameterization. Canonical largest-remainder apportionment partitions capacity and mobilized mass into gravel-and-coarser, sand, and fines. `StrictMath` attenuation under the explicit fixed grain-transport model partitions each mobile grain inventory into transport loss and arrival; fixed-unit apportionment then partitions arrival into bypass and deposition. The transport-loss and bypass quantities additionally derive bounded receiving roles—intermediate route storage and downstream continuation—without inventing an exact receiving body or coordinate. A separate cohesion state derives fines fraction and matrix support, then keeps cohesion-adjusted detachment distinct from the effective erodibility response. Repeated source-body claims are grouped into deterministic usage summaries, with exact capacity and mobilized-mass closure checked for every group. The deposited three-bin spectrum also derives bounded coarse, sand, and fines spread proxies and a weighted dispersion class; these are resolution aids rather than measured diameters. Every bulk equality therefore closes componentwise. Separate canonical reductions convert input deposit totals to exact mineral-mixture shares and aggregate deposited grain mass to the exact texture spectrum. The deposited three-bin spectrum also derives a bounded sorting-dominance index and coarse sorting class; this state feeds the existing texture-conditioned physical response without claiming mineral-specific distributions. The same immutable weathering availability and normalized source-versus-matrix shares derive a coarse colluvial profile class; no absolute thickness or organic reservoir is inferred. The transport-model identity, every response input, every process score, every sink role and fraction, every cohesion state, every dispersion state, every source usage summary, every bulk and grain allocation, every delivered share, and the resulting state join the canonical colluvial body-ID purpose. No mutable draw, traversal state, or query order enters this derivation.

Phase 1 compiles its effective definitions, schemas, units, citations, and parameter provenance into compact canonical JSON. Inputs are sorted by stable ID, strings are UTF-8 NFC, and the full SHA-256 digest of those bytes is frozen into `WorldIdentity`. Input list/map order and authoring whitespace therefore cannot change identity, while any effective scientific parameter change must change it. The snapshot golden is published by the tests and as `registry-snapshot.json` in the review packet.

The authored source is a packaged public JSON resource with a versioned authoring schema. Duplicate keys, trailing content, unknown fields, and unit-vocabulary changes fail before canonical compilation. JSON parser objects never enter domain APIs, and the resource is loaded once when the Phase 1 registry initializes rather than during random-access queries.

Phase 0 and Phase 1 intentionally use different model, scientific-digest, and dimension-profile identities. Phase 0 retains the fixed fertile proof grammar; Phase 1 adds deterministic grammar selection, revised deformation, explicit stratigraphy, and the validated registry digest. A Phase 1 result can therefore never masquerade as Phase 0 geology for the same numeric seed.

Phase 2 freezes its typed material catalog independently, then hashes a canonical manifest containing the unchanged Phase 1 registry digest and the material-catalog digest. Its distinct model/profile identity prevents petrologic results from masquerading as Phase 1 geology. Each body samples its authored modal-variation axes and bounded physical properties through object-keyed, purpose-separated streams, so cache state and unrelated draws cannot perturb a realization. Variation axes are canonically ordered and contain signed loadings that close to zero, making mineral covariance explicit rather than dependent on map iteration or independent per-mineral noise. Solid-solution definitions and endmember IDs are canonically sorted; resolved component volume and formula-mass-corrected mole fractions use stable largest-remainder allocation and therefore close exactly without authoring/map-order dependence. Protolith-family lists and response recipes are canonicalized before hashing, and the resolver chooses exactly one target from the immutable host family; authoring order cannot change that choice. Discrete fluid-condition axes are authored and canonicalized rather than randomly consumed during queries. Mineral modes and formula-derived bulk element mass fractions close on an exact one-million-part basis; domain-separated largest-remainder tie ranks remove iteration-order and floating-point residuals before values enter local element-delta or system reservoir ledgers. Surficial weathering targets explicitly retain the one-part-per-million native-gold carrier so exact blending cannot erase source-linked placer identity when unrelated world identity changes alter a rounding tie. A generated colluvial mantle derives a normalized uphill vector from bounded four-block central differences of deterministic Phase 1 surface elevations, then follows shared adaptive 32-block reaches whose local gradients are clipped to the initial 60-degree bearing bound before sampling deterministic local, near-upslope, and far-upslope bedrock at cumulative distances. Each contribution records its exact source point and owning province; construction validates that every point lies at its declared distance on the canonical routed path. Its transported body ID is derived through a purpose-separated object stream keyed by the local source body and separated by composition-relevant source attributes and matrix fraction. An exact N-way largest-remainder blend combines the body-keyed generic matrix and source assemblages independently of list order, after which bulk chemistry and solid-solution state are recomputed. Cache eviction and query order therefore cannot change classification, provenance, identity, modal closure, or chemistry.
