This increment asks whether the Phase 1 body/history result can resolve into a coherent bulk-rock parcel without storing mineralogy per block. It deliberately reuses the existing rift-to-arc geometry and deposit proof rather than adding another body or deposit family.

## Typed material catalog

`phase2-materials.json` is a public classpath data pack with a strict boundary. Duplicate JSON keys, trailing documents, missing or unknown fields, invalid enum values, unsupported elements, malformed namespaced IDs, unsafe citation URIs, non-closing constituent modes, unresolved constituent references, and incomplete lithology/overprint coverage all prevent Phase 2 world creation.

The first catalog contains:

- 32 ideal mineral/endmember definitions needed by the existing rock, alteration, sulfide, weathering, placer, mafic–ultramafic, and expanded sedimentary proof;
- one typed non-crystalline organic-matter constituent with exact authored bulk element mass fractions, separate from the mineral registry;
- six ideal solid-solution definitions for plagioclase, biotite, calcic amphibole, calcic clinopyroxene, olivine, and orthopyroxene;
- one primary assemblage, typed texture, and bounded physical-property distribution record for every one of the 21 currently implemented `Lithology` values;
- one metamorphic, hydrothermal, or weathering response for every implemented `Overprint` value, with non-isochemical target assemblages conditioned by exact protolith-family coverage.

Authored modes are central constituent-volume parts per million and must sum to one million. Each rock also declares one or more named modal-variation axes. An axis is a sparse set of signed constituent loadings that must sum to zero; cumulative loading on each constituent may not exceed the rock's declared modal-spread fraction. These axes encode substitution or mixture directions instead of allowing every constituent to vary independently. Rocks additionally declare a coarse texture class independent from presentation and triangular minimum/mode/maximum distributions for porosity, permeability, and erodibility. Ideal mineral formulas use a bounded element vocabulary; non-crystalline constituents instead author exact bulk element mass fractions. Whole-rock element mass fractions are derived from constituent chemistry, modal volume, and density, then closed to exactly one million parts with deterministic largest-remainder rounding. Endmember modes participating in a declared solid solution remain the authoritative bulk-composition proxies, but queries additionally interpret their combined mode as one compositional phase. The catalog labels its modes, covariance loadings, protolith-conditioned response targets, spread bounds, textures, and property distributions as proof tunables pending geological review; it does not present them as measured universal rock compositions.

## Derived query state

`Phase2World.create(seed)` returns a `MaterialQueryEngine`. The finite matrix of 21 lithologies and nine overprints is validated into immutable recipe templates once per engine. Each geological body receives one deterministic triangular score per authored modal-variation axis; applying the signed loadings produces correlated primary modes while triangular property distributions independently resolve porosity, permeability, and erodibility. All streams are keyed by world identity, stable body ID, and explicit property purpose, so querying another point or clearing a cache cannot consume or perturb a result. Integer modes close exactly to one million parts using largest-remainder allocation with domain-separated deterministic tie-breaking. A bounded cache retains resolved body/overprint recipes without becoming part of the scientific state.

A point query first obtains the immutable Phase 1 geological sample and then derives a `PetrologicSample` containing:

- the primary and resolved material-constituent assemblages;
- primary and resolved solid-solution phase states;
- constituent-derived primary and resolved bulk element composition;
- an exact local element-delta ledger and causal process attribution;
- optional typed process-fluid conditions for hydrothermal and weathering responses;
- porosity, permeability, and erodibility response;
- protolith-aware metamorphic facies and a compact P-T-t path;
- an optional linked magma-lineage pulse state;
- an optional sedimentary facies, maturity, diagenesis, and named-provenance state.

The three existing pluton pulses share the province magma-system ID and progress from diorite through granodiorite to the felsic stock. Rock names are therefore outputs of one ordered differentiation abstraction, not independent random rolls. Existing basin members retain basement provenance; the marine volcaniclastic member additionally names the magmatic lineage.

Each `SolidSolutionState` reports its total phase mode, exact one-million-part endmember volume fractions, formula-mass-corrected mole fractions, interpolated ideal formula, phase bulk composition, density, hardness, and weathering resistance. Component normalization uses deterministic largest-remainder allocation. The joins are albite–anorthite plagioclase, phlogopite–annite biotite, tremolite–ferro-actinolite calcic amphibole, diopside–hedenbergite calcic clinopyroxene, forsterite–fayalite olivine, and enstatite–ferrosilite orthopyroxene. These endmember relations are supported by published work on [plagioclase](https://hero.epa.gov/reference/3581129/), [phlogopite–annite](https://rruff.info/doclib/am/vol77/AM77_1191.pdf), [tremolite–ferro-actinolite](https://rruff.info/doclib/am/vol83/AM83_458.pdf), [calcic clinopyroxene](https://rruff.info/uploads/MM37_216.pdf), [olivine](https://rruff.info/uploads/AM53_807.pdf), and [pyroxenes](https://rruff.info/uploads/AM66_1.pdf). The model is deliberately ideal: it does not yet calculate activities, site ordering, miscibility gaps, solvi, or exsolution. This preserves an explicit upgrade path rather than presenting linear interpolation as equilibrium thermodynamics.

The first content-breadth slice adds komatiitic/ultramafic, basaltic, and gabbroic behavior classes. It distinguishes ultramafic crystalline, volcanic aphanitic, and intrusive phaneritic textures while resolving plagioclase, olivine, orthopyroxene, clinopyroxene, and magnetite proportions. The relationships follow [USGS stratiform-chromite host petrology](https://doi.org/10.3133/sir20105070E), a [USGS olivine-gabbro study](https://www.usgs.gov/publications/petrology-and-chemistry-green-acres-gabbro-complex-near-winchester-riverside-county), published [gabbro modal ranges](https://pubs.usgs.gov/publication/70016308), and [USGS basalt petrography](https://pubs.usgs.gov/pp/0214d/report.pdf). The exact modes, covariance axes, and physical-property distributions remain project proof tunables pending catalog review. These definitions are queryable and participate in every material-response validation, but Phase 1's current rift-to-arc geometry does not yet emit them as additional bodies.

The second breadth slice adds siltstone, limestone, dolostone, and chert. Siltstone provides a clastic-silt state between the existing sandstone and shale recipes; limestone and dolostone separate calcite- and dolomite-dominant carbonate chemistry; chert adds a low-porosity microcrystalline-silica behavior. Each class has explicit facies, grain-size, maturity, and diagenesis state. The relationships follow USGS descriptions of [siltstone framework and matrix](https://pubs.usgs.gov/pp/1007/report.pdf), [limestone and dolostone mineralogy](https://pubs.usgs.gov/bul/2195/b2195.pdf), [dolomitization](https://www.usgs.gov/publications/dolomitization-quaternary-reef-limestones-aitutaki-cook-islands), and [microcrystalline quartz in chert](https://pubs.usgs.gov/of/2004/1098/). Exact modes, covariance, and physical properties remain review tunables. Phase 1 geometry does not yet emit these additional facies, and its current source-body field records only the modeled terrigenous contribution rather than a typed seawater/biogenic reservoir.

The third breadth slice adds gypsum/anhydrite and halite/potash evaporite behavior classes, the gypsum, anhydrite, halite, and sylvite mineral definitions, and chlorine to the formula vocabulary. The sulfate class represents earlier gypsum/anhydrite precipitation and hydration–recrystallization state; the chloride class is halite-rich with a later sylvite component and records salt recrystallization, dissolution, and halokinesis as post-depositional behavior. The relationships follow the USGS [chemical-sedimentary deposit models](https://pubs.usgs.gov/of/2007/1214/PDF/8.0-chemical-sedimentry-FINAL.pdf), [global potash overview](https://pubs.usgs.gov/sir/2010/5090/s/), [Prairie Evaporite mineralogy](https://pubs.usgs.gov/publication/sir20105090CC), and [evaporite-dissolution hazard synthesis](https://pubs.usgs.gov/publication/70029326). Exact modes, covariance, mineral physical properties, and rock physical-property distributions remain review tunables. These definitions are queryable and participate in all material-response validation, but they do not claim that present-day aridity alone creates an evaporite basin: Phase 1 geometry does not yet implement restricted-basin concentration/reflooding gates or emit these facies. The existing sedimentary source-body field also remains a terrigenous-provenance placeholder rather than a typed brine reservoir.

The fourth breadth slice adds a subtype-neutral banded iron-formation behavior and the siderite ideal endmember. Its banded iron–silica texture and central recipe resolve fine-grained quartz, magnetite, hematite, siderite, and minor carbonate, sulfide, and clay components. USGS descriptions give this shared core mineralogy while separating laterally extensive Superior-type sheets in stable shallow-marine shelf/intracratonic settings from smaller Algoma-type beds in volcano-sedimentary greenstone basins ([Superior model 34a](https://pubs.usgs.gov/bul/b1693/html/bull971h.htm); [Algoma model 28b](https://pubs.usgs.gov/bul/b1693/html/bull1h45.htm)). The texture records centimetre-scale banding as material metadata rather than claiming literal block-scale laminae. Exact modes, covariance, siderite physical properties, and rock properties remain proof tunables. Phase 1 geometry does not emit this lithology, and neither an ancient age nor the catalog recipe selects a BIF subtype or proves formation: later body generation still requires the appropriate ocean-redox, iron-supply, low-clastic-dilution, basin, and preservation gates. Supergene silica leaching and residual iron enrichment also remain a separate future process rather than an ore grade implied by the primary recipe.

The fifth breadth slice adds coal without representing its organic fraction as a fictitious mineral. Authoring schema v6 introduces a general material-constituent boundary and a separate non-crystalline registry. The initial organic-matter definition has exact authored C–H–N–O–S bulk chemistry and density; it is a deterministic proof proxy, not a universal coal analysis. The coal recipe combines that constituent with kaolinite, quartz, muscovite, chlorite, pyrite, calcite, and siderite as mineral matter and partings. This distinction follows the USGS description of coal as organic matter plus inorganic mineral components and its separation of organically bound elements from discrete minerals ([Coal: A Complex Natural Resource](https://pubs.usgs.gov/circ/c1143/html/text.html); [geologic controls on mineral matter](https://www.usgs.gov/publications/geologic-factors-control-mineral-matter-coal)). The bulk-element fields align with the C, H, O, N, and S categories used in ultimate analysis ([USGS Circular 735 methods](https://pubs.usgs.gov/circ/c735/method.htm)). The sedimentary state records a buried-peat mire origin, organic bedding with clastic partings, compaction/dewatering, and burial maturation while deliberately leaving rank unresolved. Phase 1 does not yet generate peat bodies or supply the climate, hydrology, vegetation, accommodation, preservation, burial, or thermal-history gates required to form and rank coal, so catalog availability alone cannot create a coal seam.

Contact hornfels is an isochemical response: it changes P-T-t and physical state without changing whole-rock element inventory. Potassic, phyllic, propylitic, chloritic, gossan, regolith, and unconformity-weathering responses select exactly one target recipe for the host's `GeneticFamily`, blend its assemblage, and expose exact signed element deltas. The compact catalog now distinguishes crystalline igneous/metamorphic, sedimentary, hydrothermal, and—where preservation semantics differ—surficial targets. The relationships follow the established quartz–K-feldspar/biotite, quartz–sericite–pyrite, chlorite–epidote–carbonate, chloritic VMS-footwall, iron-oxide gossan, and quartz/clay/oxide regolith associations summarized by [USGS porphyry models](https://pubs.usgs.gov/of/2008/1321/pdf/OF081321_508.pdf), the [USGS Arctic VMS study](https://www.usgs.gov/publications/mineral-and-whole-rock-compositions-seawater-dominated-hydrothermal-alteration-arctic), and a [USGS granitic-saprolite study](https://pubs.usgs.gov/of/2006/1366/). Exact target proportions remain tunable. Surficial gossan/regolith targets retain the placer parcel's one-part-per-million native-gold carrier through integer blending, while hydrothermal gossan targets contain no gold and cannot manufacture an unbudgeted commodity. A typed `MaterialProcessLedger` separates the positive and negative sides of that normalized delta, names the causal aureole, hydrothermal system, or weathering system, and carries matching chronicle events when the supplied geological history contains them. Its additions and removals balance because both bulk compositions are normalized; it is process attribution, not a claim that the local parcel is an absolute closed mass reservoir.

Hydrothermal and weathering definitions must also author a `ProcessFluidState`; inactive and contact-isochemical responses must omit it. This is a sparse rule-table key, not a runtime equilibrium calculation. It contains a fluid medium, five-bin redox class, five-bin pH/acidity class, five-bin salinity class, four-state sulfur axis, independent chloride/reduced-sulfur/carbonate/fluorine-boron capacities on `0..3`, and an integrated fluid-flux class on `0..3`. The pH bins correspond to `<3`, `3–5.5`, `5.5–8.5`, `8.5–10.5`, and `>10.5`; salinity bins correspond to `<0.5`, `0.5–3.5`, `3.5–10`, `10–30`, and `>30` wt% NaCl equivalent. Current assignments are explicit proof tunables pending scientific review.

System-scale inventory remains coarse but is now exposed through typed `ElementReservoirLedger` values. Each formed mineral-system decision is compiled from its exact fixed-point source ledger into an initial source reservoir and explicitly typed deposit, retained-source, diffuse-halo/loss, or transport-loss transfers. Ledgers require exact closure and a formed deposit must receive a deposit allocation. Point and surface samples carry the ledger for a deposit they intersect, including the existing porphyry Cu budget and the upstream-source/trap allocation for placer Au. This adds queryable conservation semantics without introducing new deposit geometry or invented inventory numbers.

## Column and surface projection

`MaterialQueryEngine.column` projects the existing Phase 1 interval proof rather than sampling every block again. It resolves one material state per geological run, retains the underlying transition/candidate/complexity evidence, and returns contiguous `PetrologicRun` values. Exhaustive block-center tests prove that every compressed state equals an independent point-material query, including across cache eviction and fresh engine construction.

`MaterialQueryEngine.surface` resolves the existing surface fields into one of three explicit relationships: exposed bedrock, in-situ regolith, or transported alluvial placer. Bedrock and regolith retain their source body identity. A placer parcel instead uses the formed placer deposit identity/age, names the upstream porphyry deposit, and carries the existing coarse Au source and trap allocations (`100000` source and `20000` trapped `phase0_fixed_units`). A hydraulic trap in a barren province cannot manufacture alluvial placer material.

## Deliberate limits

This is not the Phase 2 exit candidate. The catalog now covers 21 of the planned approximately 38 lithology classes, 32 of approximately 50 mineral/endmember definitions, and one non-crystalline constituent definition. It does not yet provide the remaining content breadth, restricted-basin evaporite generation, Superior/Algoma BIF body generation and ocean-redox gating, peat/coal body generation and rank-resolving burial/thermal history, non-ideal solid-solution thermodynamics/order/exsolution, lithology-specific response calibration beyond the current coarse genetic families, typed chemical/biogenic/brine/organic sediment reservoirs, reviewed property and fluid-response datasets, calibrated multi-stage reservoir transport, or presentation/processing policy. Minecraft/NeoForge realization remains deferred to Phase 4.
